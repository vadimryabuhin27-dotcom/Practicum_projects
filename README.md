# Practicum_projects
# Прикладные решения на платформе 1С:Предприятие 8.3 

В данном репозитории представлены самостоятельные конфигурации, разработанные с нуля для автоматизации предприятий сферы услуг. Логика решений ориентирована на измеримую бизнес-пользу, оптимизацию учета и минимизацию рутинных операций.

---

### Структура репозитория

* **`Груминг-салон.zip`** — выгрузка конфигурации (.dt) прикладного решения для автоматизации груминг-салонов.
* **`Салон красоты.zip`** — выгрузка конфигурации (.dt) прикладного решения для автоматизации салонов красоты.
* **`README.md`** — текущее описание проектов, технического стека и бизнес-метрик.

---

### Подробное описание проектов

#### 1. Груминг-салона
* **Цель проекта:** Автоматизация учета услуг груминг-салона.
* **Ключевой функционал:** 
  * Реализован  **складской учет** и сквозной **контроль остатков списанных товаров** (расходных материалов и косметики для животных).
  * Разработан и внедрен **бизнес-процесс закупки товаров у поставщика**, упорядочивающий цепочку снабжения.
  * Настроены и проведены **бухгалтерские проводки** в рамках конфигурации с учетом принципов регламентированного учета.
  * Интегрирована и настроена **Библиотека стандартных подсистем (БСП)** для расширения базового функционала решения.
* **Результат:** Сокращено расхождение между фактическими остатками на складе и данными в системе до 0%, полностью исключены убытки от неучтенного расхода дорогой косметики для животных.

#### 2. Автоматизация работы салона красоты
* **Цель проекта:** Автоматизация учета услуг салона красоты.
* **Ключевой функционал:**
  * Реализован  **складской учет**, а также сквозной **контроль остатков списанных товаров** на складе студии.
  * Разработана **автоматическая загрузка цен** из внешних прайс-листов (файлов Excel).
  * Настроены и проведены **бухгалтерские проводки** с учетом принципов регламентированного учета.
  * Успешно внедрена **Библиотека стандартных подсистем (БСП)**.
 * **Использованные инструменты:** инструменты тестирования (**Vanessa Automation**, **1С:Тестировщик**).
* **Результат:** Время обновления цен на услуги и товары сокращено с нескольких часов до 2 минут. Процесс полностью избавлен от ручного ввода и ошибок в чеках клиентов.

### Как запустить проекты
1. Скачайте необходимый архив (`.zip`) из этого репозитория и распакуйте его, чтобы получить файл конфигурации `.dt`.
2. Откройте 1С:Предприятие в режиме **Конфигуратор** (создав пустую информационную базу).
3. В верхнем меню выберите **Администрирование** → **Загрузить информационную базу** и укажите распакованный файл `.dt`. из этого репозитория и распакуйте его, чтобы получить файл конфигурации `.dt`.
